# 基金信息查询

输入六位基金代码，通过 AKShare 返回：

- 顶栏研究入口：基金查询、最近 12 条查询历史和自选组合集中在全局顶栏，
  在任意基金研究页面都可以快速切换；基金查询复用月度本地全量目录，
  支持代码片段、中文名称、拼音首字母及完整拼音模糊搜索
- 自选组合：在基金档案中一键收藏，按债基、偏股、指数等分类筛选；支持
  自定义基金显示名称和任意自定义分类，所有内容保存在本地 JSON 文件中，
  不依赖数据库
- 基础资料：名称、代码、类型、成立日、管理人、托管人、投资目标、业绩比较基准、管理费率、托管费率和销售服务费率
- 外部资料链接：基金标题区和股票详情可跳转雪球；债券名称使用“债券名称 + 债券代码”打开 Google 搜索
- 基金档案：成立时长、成立份额、最新净资产与份额规模、个人/机构持有比例和分档申购费率
- A/C 份额比较：合并首档申购费、按持有期限分档的赎回费和逐日销售服务费，给出买入后在不同天数赎回时的总费率与更省份额
- 净值信息：最新单位净值、累计净值及净值日期
- 历史业绩：日涨幅、近 1 月、近 3 月、近 6 月、近 1 年和近 3 年涨幅；
  阶段涨幅同步展示下游基金分类、同类平均、相对同类差异比例和同类
  排名，并对前/后 5%、10%、20% 分位进行分层标记
- 业绩走势与净值：默认展示近一年业绩走势，支持回撤修复、累计净值
  和分红记录切换；分红视图汇总次数、累计每份分红、最近分红并
  展示逐笔除息记录；最近连续 6 个月、4 个季度或 3 年均有分红时，
  会给出对应频率标识（月度优先）。时间范围支持 1 月、3 月、6 月、
  1 年、3 年、5 年、成立以来和自定义起止日期
- 赛道基准：业绩走势图可叠加沪深 300、中证 500、中证 800、
  中证货币基金指数、中债中短债财富（1-3 年）、中债中长债财富
  （5-7 年）、偏债混合
  （80% 中债新综合财富 + 20% 沪深 300）和偏股混合
  （80% 沪深 300 + 20% 中债新综合财富）基准；
  系统根据基金类型及最新披露债券结构推荐默认赛道，并计算区间
  领先/落后百分点；同一基准同步贯穿业绩走势、阶段涨幅、周期
  涨幅和回撤修复，切换后统一刷新
- 模拟持有：支持单次买入以及按周、按月定投，按单位净值与期间现金
  分红估算累计投入、投入次数、持有收益率、盈亏和期末价值
- 基金持仓：默认展示最新可用报告期，并可按需切换不同季度的股票、
  债券和基金持仓；ETF 联接基金在资产分布中保留基金投资占比，在股票
  持仓矩阵中直接穿透目标 ETF；FOF 等持有多只基金的产品不做穿透，
  直接展示基金持仓矩阵。同时提供季度报告目录和原始 PDF 链接。股票
  展示行业配置，债券展示季报完整品种结构、利率债/信用债归并，以及
  逐只披露债券明细；点击债券品种或信用属性矩阵，可查看类别定义、
  主要特点、收益来源、核心风险、观察重点和当前组合暴露解读
- 股票持仓指标：展示每只持仓股票所属行业，查询其 PE(TTM)、PB(MRQ)，以 PB/PE
  推算 ROE，并按近 12 个月现金分红和最新价计算股息率；同时按持仓
  权重汇总组合指标
- 股票详情：点击持仓股票名称，可查看基础资料、最新价格、PE、PB、推算
  ROE、近 12 个月股息率、最新交易日换手率，以及前复权日收盘价曲线；
  曲线支持成立以来、5 年、3 年、1 年、6 月、3 月和 1 月切换
- 资产分布：从最新季度报告提取股票、债券、基金和其他资产的总资产占比
- ETF 联接穿透：自动识别唯一目标 ETF，股票持仓默认展示目标 ETF 的
  底层股票和行业配置；同时保留联接基金自身的直接持仓标签

净值以元为单位；持仓中的占净值比例和持仓市值分别以 `%`、`万元`
为单位，股票持股数以 `万股` 为单位。纯债基金会自动回溯并展示最新
可用年度的债券季度持仓。

股票行业配置来自 AKShare 的基金定期报告行业配置接口。债券不再套用
股票行业概念：品种结构取最新季报的完整债券组合，信用属性按公开规则
归并；长短债结构仅覆盖定期报告列示的前几大债券，并按报告期末至最终
到期日的剩余年限划分，因此不能替代基金完整组合的久期指标。

资产分布采用季度报告中的“占基金总资产比例”口径，四类合计为 100%；
“其他”汇总现金、买入返售、衍生品及其他各项资产。该口径与持仓明细
中的“占基金净值比例”不同，债券基金因杠杆导致的净值占比超过 100%
不会使资产分布图失真。

债券信用属性中，利率债包括国债、央票、政策性金融债和地方政府债；
信用债包括非政策性金融债、企业债、短融和中票。债券品种及到期日通过
AKShare 的中国货币网接口补充；含权债的期限分类暂按最终到期日计算。

## 安装

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## 启动网页与 HTTP API

```bash
uvicorn app:app --reload --port 8765
```

然后打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。

HTTP 接口：

```text
GET /api/funds/{fund_code}
GET /api/funds/{fund_code}?refresh=true
GET /api/funds/search?q=华夏成长&limit=10
GET /api/watchlist
PUT /api/watchlist/{fund_code}
DELETE /api/watchlist/{fund_code}
GET /api/benchmarks
GET /api/benchmarks/{benchmark_key}
GET /api/funds/{fund_code}/holdings?period=2026Q1
GET /api/stocks/{stock_code}
GET /api/stocks/{stock_code}?refresh=true
GET /health
```

例如：

```bash
curl "http://127.0.0.1:8765/api/funds/000001"
```

交互式 API 文档位于
[http://127.0.0.1:8765/docs](http://127.0.0.1:8765/docs)。

自选组合持久化到 `.data/watchlist.json`。该文件会在第一次收藏基金时自动
创建，并使用临时文件原子替换写入；它属于本机个人数据，已加入 `.gitignore`。
无需安装或运行任何数据库。
基金详情按基金代码持久化到
`.cache/funds/{fund_code}.json`，其中主详情固定返回最多 20 条持仓。正常查询沿用日缓存，
只在工作日收盘后的 15:30 更新窗口重新查询；页面“强制刷新”按钮和
`refresh=true` 会立即跳过缓存。收盘后自动更新失败时继续返回旧缓存，
并每 30 分钟重试。指定季度持仓接口仍使用十分钟缓存。

股票详情按代码持久化到 `.cache/stocks/{stock_code}.json`。正常打开会沿用
日缓存，只在工作日收盘后的 15:30 更新窗口重新查询；周末沿用最近交易日
数据。弹窗中的“强制刷新”会使用 `refresh=true` 跳过日缓存并立即查询上游。
收盘后自动更新失败时继续返回旧缓存，并每 30 分钟重试。

赛道基准历史行情会按基准分别持久化到
`.cache/benchmarks/{benchmark_key}.json`。工作日 20:00 后检查一次新数据，
周末沿用最近一次结果至下一个工作日更新窗口；上游临时不可用时继续返回
旧数据，并每 30 分钟重试。响应头 `X-Cache`、`X-Cache-Status`、
`X-Data-Date` 和 `X-Next-Refresh` 分别用于识别命中状态、数据新鲜度、
数据日期和下次检查时间。

## 命令行使用

```bash
python fund_lookup.py 000001
```

限制持仓返回数量：

```bash
python fund_lookup.py 000001 --holdings-limit 10
```

在其他 Python 代码中调用：

```python
from fund_lookup import get_fund_data

result = get_fund_data("000001")
print(result["基础资料"])
```

AKShare 聚合的上游网站可能临时不可用。程序会尽可能降级获取，并把失败信息放在返回结果的 `提示` 字段中。
