# 基金信息查询

输入六位基金代码，通过 AKShare 返回：

- 基础资料：名称、代码、类型、成立日、管理人、托管人、投资目标、业绩比较基准、管理费率和托管费率
- 基金档案：成立时长、成立份额、最新净资产与份额规模、个人/机构持有比例和分档申购费率
- 净值信息：最新单位净值、累计净值及净值日期
- 历史业绩：日涨幅、近 1 月、近 3 月、近 6 月、近 1 年和近 3 年涨幅
- 区间收益与净值：默认展示近一年区间收益走势，支持累计净值、单位
  净值和分红记录切换；分红视图汇总次数、累计每份分红、最近分红并
  展示逐笔除息记录。时间范围支持 1 月、3 月、6 月、1 年、3 年、
  5 年、成立以来和自定义起止日期，单位净值视图同时标注分红事件
- 模拟持有：支持单次买入以及按周、按月定投，按单位净值与期间现金
  分红估算累计投入、投入次数、持有收益率、盈亏和期末价值
- 基金持仓：最新可用报告期的股票/债券持仓明细；股票展示行业配置，债券展示季报完整品种结构、利率债/信用债归并，以及披露债券的剩余期限结构
- 资产分布：从最新季度报告提取股票、债券、基金和其他资产的总资产占比
- ETF 联接穿透：自动识别目标 ETF，展示目标 ETF 的底层股票持仓和
  行业配置；同时保留联接基金自身的直接持仓

净值以元为单位；持仓中的占净值比例和持仓市值分别以 `%`、`万元`
为单位，股票持股数以 `万股` 为单位。纯债基金会自动回溯并展示最新
可用年度的债券季度持仓。

股票行业配置来自 AKShare 的基金定期报告行业配置接口。债券不再套用
股票行业概念：品种结构取最新季报的完整债券组合，信用属性按公开规则
归并；长短债结构仅覆盖定期报告列示的前几大债券，并按报告期末至最终
到期日的剩余年限划分，因此不能替代基金完整组合的久期指标。

资产分布采用季度报告中的“占基金总资产比例”口径，四类合计为 100%；
“其他”汇总现金、买入返售、衍生品及其他各项资产。该口径与持仓明细
中的“占基金净值比例”不同，债券基金因杠杆导致的净值占比超过 100%
不会使资产分布图失真。

债券信用属性中，利率债包括国债、央票、政策性金融债和地方政府债；
信用债包括非政策性金融债、企业债、短融和中票。债券品种及到期日通过
AKShare 的中国货币网接口补充；含权债的期限分类暂按最终到期日计算。

## 安装

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## 启动网页与 HTTP API

```bash
uvicorn app:app --reload --port 8765
```

然后打开 [http://127.0.0.1:8765](http://127.0.0.1:8765)。

HTTP 接口：

```text
GET /api/funds/{fund_code}
GET /api/funds/{fund_code}?holdings_limit=10
GET /api/funds/{fund_code}?refresh=true
GET /health
```

例如：

```bash
curl "http://127.0.0.1:8765/api/funds/000001?holdings_limit=10"
```

交互式 API 文档位于
[http://127.0.0.1:8765/docs](http://127.0.0.1:8765/docs)。
相同基金代码和持仓数量的查询结果默认缓存十分钟；使用
`refresh=true` 可跳过缓存。

## 命令行使用

```bash
python fund_lookup.py 000001
```

限制持仓返回数量：

```bash
python fund_lookup.py 000001 --holdings-limit 10
```

在其他 Python 代码中调用：

```python
from fund_lookup import get_fund_data

result = get_fund_data("000001")
print(result["基础资料"])
```

AKShare 聚合的上游网站可能临时不可用。程序会尽可能降级获取，并把失败信息放在返回结果的 `提示` 字段中。
